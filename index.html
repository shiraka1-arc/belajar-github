Materi Pembelajaran

Pilih materi untuk mulai mempelajari konsep dasarnya.

DASAR

01. Linux Fundamentals

Kenali sistem operasi Linux dan perintah dasar terminal.

Konsep Dasar Linux

Linux banyak digunakan pada server dan lingkungan keamanan siber.

  • pwd — melihat direktori saat ini.
  • ls — melihat isi direktori.
  • cd — berpindah direktori.
  • mkdir — membuat direktori.
  • cat — membaca isi file teks.

Latihan: coba perintah tersebut pada terminal Linux milikmu.

DASAR

02. Computer Networking

Pelajari bagaimana perangkat saling terhubung dan berkomunikasi.

Konsep Dasar Jaringan

  • IP Address: alamat perangkat dalam jaringan IP.
  • DNS: menerjemahkan nama domain menjadi informasi alamat.
  • TCP: komunikasi yang berorientasi koneksi.
  • Port: nomor yang mengidentifikasi layanan jaringan.
  • HTTP/HTTPS: protokol komunikasi web.

Latihan: pelajari hasil perintah ipconfig di Windows atau ip addr di Linux.

PEMROGRAMAN

03. Python Fundamentals

Dasar Python

Contoh program sederhana:

WEB SECURITY

04. Web Security Basics

Kenali cara kerja aplikasi web dan risiko keamanannya.

Konsep Keamanan Web

  • HTTP request dan response.
  • Cookie dan session.
  • Autentikasi dan otorisasi.
  • Cross-Site Scripting (XSS).
  • SQL Injection dan validasi input.

Fokuslah memahami penyebab kerentanan dan cara mencegahnya. Praktikkan hanya pada lab legal, seperti Web Security Academy.

PENGUJIAN KEAMANAN

05. Ethical Hacking

Kenali proses pengujian keamanan sistem secara bertanggung jawab.

Tahapan Pengujian

  • Menentukan ruang lingkup dan izin.
  • Mengumpulkan informasi yang diizinkan.
  • Mengidentifikasi potensi kerentanan.
  • Melakukan pengujian di lingkungan yang disetujui.
  • Mendokumentasikan hasil dan rekomendasi perbaikan.

Jangan menguji sistem orang lain tanpa izin yang jelas.

TOOLS

06. Security Tools

Kenali fungsi alat yang sering dipakai untuk belajar keamanan siber.

Alat untuk Pemula

  • Wireshark: menganalisis lalu lintas jaringan.
  • Nmap: memetakan host dan layanan yang terdeteksi.
  • Burp Suite: memeriksa dan menguji lalu lintas aplikasi web.
  • Git: mengelola versi kode dan proyek.

Gunakan alat hanya pada perangkat, jaringan, dan aplikasi yang kamu miliki atau yang secara eksplisit mengizinkan pengujian.
